# Семестр

Учебный дашборд в тёплом минималистичном стиле: расписание пар, файлы по предметам, дедлайны и уведомления. Работает прямо в браузере, без сервера и регистрации. Все данные хранятся локально в этом браузере.

## Что умеет

**Главная**
- Приветствие по времени суток, текущая неделя (числитель или знаменатель).
- Поле быстрого ввода. Напишите «сдать лабу по Python в пятницу в 18:00», и срок распознается сам. Понимает «сегодня», «завтра», «послезавтра», дни недели, «12 октября», «25.10», «через 2 часа», «в 9 утра».
- К полю можно прикрепить файлы: скрепкой или перетаскиванием на страницу.
- Карточки «Сегодня» (идущая пара с полосой прогресса, время до следующей), «Дела и дедлайны», «Недавние файлы».

**Расписание**
- Неделя в виде сетки, линия «сейчас», переключение недель.
- Пары по числителю или знаменателю. Первая неделя семестра задаётся в настройках.
- Время пар по номеру (1-я пара 08:30–10:00 и т. д.) или своё.
- Клик по пустому месту в сетке открывает новую пару с уже подставленным временем.
- На телефоне расписание показывается списком по дням.

**Файлы**
- Загрузка кнопкой или перетаскиванием, хранение в IndexedDB.
- Фильтр по предметам, поиск, вид плиткой или списком.
- Просмотр картинок, PDF, текста и кода, аудио и видео. Скачивание и удаление.

**Уведомления**
- Лента: напоминания о парах (за 5–60 минут), о дедлайнах, о новых файлах.
- Напоминания и дедлайны с отметкой «выполнено».
- Системные уведомления браузера (нужно разрешение). Они приходят, пока сайт открыт во вкладке.

**Настройки**
- Имя, тема (светлая, тёмная, системная), время напоминаний о парах, начало семестра.
- Резервная копия в JSON и восстановление из неё. Полная очистка данных.

При первом запуске показывается пример расписания и файлов. Убрать его можно кнопкой «Очистить пример» на главной или в настройках.

## Как запустить

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

Для локального сервера (удобнее для IndexedDB в некоторых браузерах):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

### Публикация на GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку и папку `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Устройство

```
index.html        разметка каркаса
css/styles.css    палитра, типографика, анимации, адаптив
js/utils.js       даты, склонения, разбор сроков из текста, иконки
js/store.js       состояние в localStorage, файлы в IndexedDB, пример данных
js/ui.js          тосты, модальные окна, поповеры, переключатели
js/schedule.js    расписание и редактор пар
js/files.js       загрузка, просмотр и перетаскивание файлов
js/notify.js      лента, напоминания, планировщик уведомлений
js/home.js        главная и поле быстрого ввода
js/settings.js    настройки, резервные копии
js/app.js         маршруты, боковая панель, тема, запуск
```

Код на чистом JavaScript без фреймворков. Шрифты Onest и Source Serif 4 подключаются из Google Fonts. Анимации отключаются, если в системе включено «уменьшение движения».

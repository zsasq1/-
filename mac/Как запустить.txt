СЕМЕСТР ДЛЯ MAC

Всё хранится на этом Mac, в папке «Данные» рядом с Семестром:
расписание, дела, заметки к занятиям и файлы любого размера, разложенные по предметам.
Интернет не нужен (только чтобы подтянуть шрифты — без него будут системные).

ПЕРВЫЙ ЗАПУСК
1. Перетащите папку «Семестр» туда, где она будет жить, — например, в «Документы».
   Не оставляйте её в «Загрузках»: её легко случайно удалить вместе с данными.
2. Дважды щёлкните «Семестр.command».
   Если macOS пишет, что не может проверить разработчика:
   Системные настройки → Конфиденциальность и безопасность → внизу «Всё равно открыть»,
   затем снова дважды щёлкните «Семестр.command».
   Если macOS предложит установить «Инструменты командной строки» — согласитесь,
   это нужно один раз (там Python, на котором работает Семестр).
3. Откроется Терминал и браузер с Семестром по адресу http://localhost:8417
   Окно Терминала не закрывайте, пока пользуетесь Семестром — его можно свернуть.

ДАЛЬШЕ
Каждый раз запускайте «Семестр.command». Удобно добавить его в Dock:
перетащите файл на правую часть Dock, рядом с Корзиной.
В Safari можно сделать Семестр отдельным приложением: Файл → Добавить в Dock.

ПЕРЕНЕСТИ ДАННЫЕ ИЗ ДРУГОЙ ВЕРСИИ
В старой версии: Настройки → Резервная копия → Скачать.
Здесь: Настройки → Резервная копия → Восстановить и выберите скачанный файл.
Файлы в резервную копию не входят — загрузите их заново.

ОБНОВЛЕНИЕ
Замените папку «app» и файл «server.py» новыми. Папку «Данные» не трогайте.

ЕСЛИ ДВОЙНОЙ ЩЕЛЧОК НЕ РАБОТАЕТ
Откройте Терминал (Программы → Утилиты), напишите  python3  и пробел,
перетащите в окно файл server.py и нажмите Enter.

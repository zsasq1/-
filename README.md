# Семестр

Учебный дашборд в тёплом минималистичном стиле для студента 3 курса лечебного факультета Кировского ГМУ: расписание группы, файлы по дисциплинам, отработки, дедлайны и уведомления. Работает прямо в браузере, без сервера и регистрации. Все данные хранятся локально в этом браузере.

## Расписание Кировского ГМУ

В сайт встроено официальное расписание 3 курса лечебного факультета на первое полугодие 2026/27 (группы 301–317, версия от 2 сентября 2026, [страница лечебного факультета](https://kirovgma.ru/lechebnyy-fakultet-raspisanie)).

- На главной выберите номер группы. Появится список дисциплин: обязательные отмечены, дисциплины по выбору нужно отметить самому.
- Учитываются 1 и 2 неделя, сроки дисциплин (например, топографическая анатомия до ноября), разовые занятия и переносы на отдельные даты.
- Для лекций подставляются корпус и аудитория, для практических — кафедра или клиническая база.
- Если расписание поменяли, скачайте свежий .xlsx своего потока с сайта КГМУ и загрузите его в **Настройки → Учёба → Файл расписания**.
- Любое занятие можно исправить вручную. Пары, добавленные вручную, при обновлении не пропадают.
- Дисциплины по выбору отмечаются по курсам: диетология, латинская фармацевтическая терминология, статистика в доказательной медицине, биохимические основы ЗОЖ, межкультурная коммуникация, молекулярные механизмы в патологии человека, функциональная диагностика донозологических состояний. Время, период, аудитория и кафедра у каждого курса берутся из таблицы (например, у диетологии лекции по пятницам, а практические по понедельникам с 5 октября).
- У группы 314 по умолчанию подключён электив кафедры патофизиологии (пятница). Какой именно курс — выбирается в карточке занятия; остальные курсы по выбору отмечаются в **Настройки → Учёба → Группа**.

## Темы занятий

К каждой лекции и практическому занятию подставлена тема из [рабочих программ дисциплин КГМУ](https://kirovgma.ru/sveden/education/programs/lechebnoe-delo-31.05.01.html) (файл `js/data/kgmu-topics.js`, 5 и 6 семестр) — для всех обязательных дисциплин и всех курсов по выбору. Если в программе есть лист изменений, взята свежая редакция: у пропедевтики — план на 2026/2027 учебный год. По физкультуре в программе только разделы без порядка по датам, поэтому тем у неё нет.

- Темы раскладываются по датам по порядку с учётом длительности занятия в академических часах и праздников (4 ноября занятий нет). Для группы 314 по большинству дисциплин число часов в расписании совпадает с программой один в один.
- Итоговые и контрольные занятия помечены.
- По клику на занятие открывается карточка: тема и её содержание, номер занятия, список всех тем семестра, поле для своей темы (если кафедра идёт в другом темпе) и заметка («взять халат», вопросы к преподавателю).
- Тема попадает и в напоминание о паре.

## Что умеет

**Главная**
- Приветствие по времени суток, текущая неделя (числитель или знаменатель).
- Поле быстрого ввода. Напишите «отработка по патанатомии в пятницу в 15:45», и срок распознается сам. Понимает «сегодня», «завтра», «послезавтра», дни недели, «12 октября», «25.10», «через 2 часа», «в 9 утра».
- К полю можно прикрепить файлы: скрепкой или перетаскиванием на страницу.
- Карточки «Сегодня» (идущая пара с полосой прогресса, время до следующей), «Дела и дедлайны», «Недавние файлы».

**Расписание**
- Неделя карточками: у каждого дня — сводка («3 занятия · 08:00–15:30»), у каждого занятия — время и длительность, предмет, тип и номер («Практическое занятие 6 из 17»), аудитория и база, тема по рабочей программе целиком, ваша заметка, отметки «итоговое» и «1 нед / 2 нед». Текст не обрезается.
- У сегодняшних занятий — «Через 40 мин» или «Идёт · осталось 25 мин» с полосой; дедлайны дня — тут же, отдельными карточками; праздники отмечены.
- В шапке — сводка недели: занятия, итоговые, дедлайны. На компьютере можно переключиться на сетку «По времени» с линией «сейчас»; клик по пустому месту в ней открывает новое занятие с подставленным временем.
- Занятия по 1 или 2 неделе (или по числителю и знаменателю — переключается в настройках), с периодом действия или только в отдельные даты.

Никаких напоминающих плашек: на главной появляется только выбор группы, пока расписание не загружено. Новые версии ставятся сами и включаются при следующем открытии.

**Файлы**
- Загрузка кнопкой или перетаскиванием, хранение в IndexedDB.
- Фильтр по предметам, поиск, вид плиткой или списком.
- Просмотр картинок, PDF, текста и кода, аудио и видео. Скачивание и удаление.

**Уведомления**
- Лента: напоминания о парах (за 5–60 минут), о дедлайнах, о новых файлах.
- Напоминания и дедлайны с отметкой «выполнено».
- Итоговые и зачётные занятия сами попадают в дедлайны: название предмета, какое итоговое, когда и где, и «Что надо знать» — темы раздела по рабочей программе от прошлого итогового до этого, с датами, когда их проходили. Отметка «Сдано» убирает итоговое в выполненные. За три дня и накануне приходит напоминание с темами для повторения; в файле календаря у итогового тоже есть список тем.
- Системные уведомления браузера (нужно разрешение). Они приходят, пока сайт открыт во вкладке.

**Настройки**
- Имя, тема (светлая, тёмная, системная), время напоминаний о парах, начало семестра.
- Резервная копия в JSON и восстановление из неё. Полная очистка данных.

При первом запуске показываются примеры дел и файлов (шпаргалка по рецептуре, список микропрепаратов, схема ЭКГ). Убрать их можно кнопкой «Очистить пример» на главной или в настройках.

## Ассистент

Кнопка «Ассистент» в правом нижнем углу открывает чат. Пишете обычными словами — «добавь отработку по фарме в пятницу в 15:45», «запиши к завтрашней пропедевтике взять фонендоскоп», «что учить к ближайшему итоговому», «перенесли гигиену на 20.10 в 13:00» — и ассистент сам работает с вашими данными:

- **расписание:** смотрит пары и темы по рабочей программе за любой период, добавляет разовые и еженедельные занятия, отменяет пару в конкретный день и переносит её на другой день или время;
- **дела:** добавляет, меняет, отмечает выполненными и удаляет дедлайны и напоминания, умеет добавить сразу целый план подготовки по дням;
- **занятия:** пишет заметки и свою тему, отмечает пропуск (сам создаёт дело «Отработка»), отработку и оценку, считает средний балл и неотработанные пропуски;
- **итоговые:** говорит, что учить, отмечает сданными;
- **файлы:** читает файлы из «Файлов» — текст, Word, PowerPoint (PDF и картинки — с ключом Claude), сохраняет конспекты в «Файлы», переименовывает и раскладывает по предметам;
- **вложения:** к сообщению можно прикрепить фото доски или расписания, PDF, Word, PowerPoint — ассистент прочитает и при желании сохранит в «Файлы»;
- **тренировка:** гоняет по вопросам к итоговому, сохраняет карточки на темы с ошибками, повторяет их по интервалам (чем лучше помнишь — тем реже) и выгружает колоду для Anki (Файл → Импорт);
- **настройки:** тема, за сколько минут напоминать о паре, имя; открывает выгрузку в календарь телефона.

Пропуск и оценку можно отметить и вручную — в окне занятия («Был / Пропустил», «Оценка»); на карточке занятия появляется отметка.

Всё сделанное видно строками под ответом, и одной кнопкой «Отменить изменения» можно вернуть как было.

Как подключить:
- **В версии внутри Claude** — работает сразу через ваш аккаунт Claude, отдельно платить не нужно (расходуются лимиты подписки). Перед первым ответом Claude спросит разрешение.
- **На сайте и на Mac** — «Настройки → Ассистент → Вставить ключ». Подходит ключ Claude (platform.claude.com; модели Opus 5.5 по умолчанию, Sonnet 5.5, Haiku 5.5) или DeepSeek (platform.deepseek.com; DeepSeek V4.1 Flash по умолчанию или V4 Pro) — сервис определяется по ключу сам. Запросы оплачиваются по тарифу выбранного сервиса. Ключ хранится только в этом браузере: в хранилище, на другие устройства и в резервную копию он не попадает.
## Приложение на телефоне

Семестр можно установить как приложение: значок на главном экране, открывается без адресной строки и работает без интернета (расписание, темы, дела и файлы хранятся на устройстве).

1. Включите GitHub Pages: в репозитории **Settings → Pages → Build and deployment → Deploy from a branch**, ветка `claude/study-dashboard-files-schedule-qi7u0z` (или `main` после слияния), папка `/ (root)`, **Save**.
   На бесплатном тарифе GitHub Pages работает только для публичных репозиториев: если репозиторий закрытый, сначала сделайте его публичным (**Settings → General → Danger Zone → Change visibility**).
2. Через 1–2 минуты сайт откроется по адресу `https://zsasq1.github.io/-/`.
3. **Android (Chrome):** на главной появится «Установить», или меню ⋮ → «Установить приложение».
   **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

Когда выходит новая версия, приложение скачивает её в фоне и показывает кнопку «Обновить». После правок в файлах приложения запустите `python3 tools/sw-version.py` — он пересчитает версию в `sw.js`.

Установка и офлайн-режим работают только по https (GitHub Pages) или на `localhost`; при открытии `index.html` как файла сайт работает, но без установки.

## Сайт на всех устройствах

Семестр — обычный сайт на GitHub Pages: `https://zsasq1.github.io/-/`. Чтобы ваши данные были одинаковыми на всех телефонах и компьютерах, они хранятся в **вашем закрытом репозитории на GitHub** (например, `semestr-data`) — их видите только вы.

1. **Опубликовать сайт** (один раз): репозиторий Семестра должен быть публичным — **Settings → General → Danger Zone → Change visibility → Public** (в коде нет личных данных), затем **Settings → Pages → Deploy from a branch** → ветка и папка `/ (root)` → **Save**.
2. **Подключить хранилище** (один раз, на любом устройстве): «Настройки → Данные → Все устройства → Подключить» и три шага: создать закрытый репозиторий `semestr-data`, создать ключ доступа (fine-grained token: репозитории `semestr-data` и сам сайт, Contents — Read and write) и вставить ключ. Семестр проверит, что ключ подходит, а хранилище закрытое.
3. **Пароль**: сразу после подключения Семестр попросит придумать пароль. Ключ доступа, зашифрованный этим паролем (AES-GCM, ключ из пароля через PBKDF2 — 600 000 шагов), сохраняется в репозиторий самого сайта (`vault.json`), поэтому ключу нужен доступ и к нему. Без пароля файл бесполезен; сам пароль нигде не хранится.
4. **Другие устройства**: откройте сайт — появится экран входа, введите пароль. Или «Настройки → Данные → Другое устройство» — QR-код для камеры телефона. «Выйти» стирает данные с этого устройства (в хранилище всё остаётся). Забыли пароль — «Забыли пароль?» на экране входа: подключите хранилище ключом и задайте новый.

Каждое изменение сохраняется в хранилище через секунду, другие устройства подхватывают его за 20 секунд или сразу, когда вы к ним вернётесь. Изменения с двух устройств одновременно объединяются. Без интернета всё работает и сохраняется, когда связь появится. Файлы — до 50 МБ каждый. На чужом телефоне после работы нажмите «Отключить» в настройках.

## Семестр для Mac — всё на диске, без ограничений

`python3 tools/build-mac.py` собирает `dist/Семестр-для-Mac.zip`. Внутри папка «Семестр»: двойной щелчок по `Семестр.command` запускает маленький сервер (`server.py`, только стандартный Python) и открывает Семестр в браузере по адресу `http://localhost:8417`. Всё хранится в папке «Данные» рядом:

```
Данные/semestr.json      расписание, дела, заметки, настройки
Данные/Файлы/<Предмет>/  загруженные файлы любого размера, по предметам
Данные/Копии/            копия данных за каждый день (последние 60)
Данные/Корзина/          удалённые файлы, 30 дней
```

Файлы пишутся прямо на диск, без копии в браузере, и открываются по ссылке — даже большие видео. Сменили предмет у файла — он переезжает в папку предмета. Если сервер выключен, изменения ждут в браузере и попадают на диск после запуска. Сервер отвечает только этому компьютеру и только самому Семестру. Подробная инструкция — `mac/Как запустить.txt`.

## Где хранятся данные

- **Через Claude** (ссылка на Семестр в claude.ai или в приложении Claude): расписание, дела, заметки и файлы сохраняются в вашем аккаунте. Они не пропадают после перезагрузки и одинаковы на телефоне и компьютере. Изменения с другого устройства приходят сами за несколько секунд. Если что-то поменяли на двух устройствах одновременно, изменения объединяются. Файлы до 20 МБ хранятся в аккаунте; PDF и картинки — как есть, остальные форматы (Word, PowerPoint и т. д.) упаковываются в текст и распаковываются при открытии. Файл больше 20 МБ остаётся только на устройстве, где его добавили.
- **На сайте с подключённым хранилищем**: в вашем закрытом репозитории на GitHub, одинаково на всех устройствах (см. выше).
- **В «Семестре для Mac»**: в папке «Данные» на диске, без ограничений на размер (см. выше).
- **На сайте или из отдельного файла**: данные хранятся в этом браузере на этом устройстве (localStorage и IndexedDB). Не очищайте данные сайта и иногда скачивайте резервную копию в настройках.

Состояние видно в **Настройки → Данные**.

## Календарь телефона

Кнопка «В календарь» на странице расписания (и в настройках) сохраняет файл `.ics`: все занятия с темами, аудиторией и номером занятия, а также дедлайны и напоминания со сроком. Можно выбрать период (с сегодняшнего дня или весь семестр) и за сколько минут календарь напомнит о паре. Праздничные дни пропускаются, время указано по Кирову (UTC+3), поэтому не собьётся на телефоне с другим часовым поясом.

- **iPhone:** в просмотре файла (из «Файлов», Telegram и т. п.) кнопки «Добавить все» нет. Отправьте файл себе через «Поделиться» → «Почта», откройте письмо в приложении «Почта», нажмите на вложение → «Добавить все».
- **Android:** откройте скачанный файл — телефон предложит календарь. Если не предлагает, импортируйте файл на calendar.google.com: Настройки → «Импорт и экспорт».
- **Одно занятие:** в карточке занятия кнопка «В календарь» открывает Google Календарь с уже заполненным событием или сохраняет файл с одним занятием.

Готовый файл для группы 314 лежит в `calendar/semestr-314.ics` (с GitHub Pages — `https://zsasq1.github.io/-/calendar/semestr-314.ics`). Пересобрать его или сделать для другой группы: `node tools/build-ics.js 314` (добавьте `all`, чтобы взять весь семестр, а не только оставшиеся занятия).

Календарь не обновляется сам: если расписание поменялось, выгрузите файл заново. Удобно держать учёбу в отдельном календаре, чтобы его можно было очистить перед повторной выгрузкой.

## Как запустить

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

Для локального сервера (удобнее для IndexedDB в некоторых браузерах):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

### Один файл для компьютера

`python3 tools/build-single.py` собирает всё приложение в `dist/semestr.html`. Этот файл можно скачать и открыть двойным щелчком в любом браузере — сайт и интернет не нужны, данные хранятся в этом браузере. Установка на телефон и офлайн-кеш в таком режиме не работают.

### Публикация на GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку и папку `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

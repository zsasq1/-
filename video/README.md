# Видео-лекция: Кровотечения. Стаз. Тромбоз. Шок. ДВС. Эмболия. Ишемия. Инфаркт. Отёки

Remotion-проект, собранный из текста презентации (117 слайдов → 60 сцен + 10 заставок разделов).

- `src/lecture.json` — сцены: заголовок, пункты на экране, текст для озвучки, номера исходных слайдов.
- `SCRIPT.md` — текст для записи голоса (генерируется: `npm run script`).
- `public/voice/` — сюда кладутся записи `01.m4a … 60.m4a`.

## Сборка
```bash
npm install
npm run voice    # обработка записей: обрезка тишины, нормализация громкости, длительности
npm run studio   # предпросмотр в браузере
npm run render   # итоговое видео → out/lecture.mp4
```
Длина каждой сцены подстраивается под длину записи; сцены без записи идут по оценочному времени.
